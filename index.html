사는 조건
사는 조건 자세히 보기

시가는 오늘 아침 장이 열릴 때 처음 정해진 가격이에요. "시가보다 1~5% 올랐다"는 건 오늘 하루 동안 힘있게 오르고 있다는 뜻이에요.

"오늘 최고가에서 1%까지 밀려도 OK"는, 많이 올랐다가 다시 떨어지는 중인 주식은 피하려는 조건이에요. 아직 최고가 근처에서 버티는 주식만 사요.

"어제보다 15%까지만"은 너무 많이 오른 주식을 피하는 조건이에요. 하루에 30%까지 오를 수 있는데(상한가), 그 근처는 가격이 너무 크게 출렁여요.

사고팔 때 드는 돈(수수료·세금)

주식을 사고팔 때마다 증권사와 나라에 내는 돈이에요. 가짜 계좌도 이만큼 빼서 실제와 비슷하게 계산해요.

국내 주식
해외 주식 (미국)
해외주식 양도소득세 (1년 단위)
각 항목이 무슨 뜻인지 자세히 보기

수수료: 증권사가 "주문을 대신 넣어준 값"으로 가져가는 돈이에요. 100만원어치를 사면 0.015%인 150원을 내요. 증권사나 이벤트마다 달라서, 쓰는 곳에 맞게 바꿔주세요.

증권거래세: 국내 주식을 팔 때만 나라에 내는 세금이에요(0.20%). 100만원어치를 팔면 2,000원이에요.

슬리피지: 생각한 가격보다 조금 손해 보고 사지거나 팔리는 차이예요. 1만원에 사려 했는데 10,005원에 사지는 식이죠. 가짜 계좌는 늘 원하는 가격에 바로 사진다고 계산해서, 매매가 많을수록 실제보다 좋아 보여요. 그래서 이만큼 미리 빼요.

SEC Fee: 미국 주식을 팔 때 미국 금융당국에 내는 아주 작은 수수료예요.

환전 비용: 원화를 달러로(살 때), 달러를 원화로(팔 때) 바꿀 때마다 빠지는 돈이에요. 토스증권은 평일 낮에 약 0.05%, 그 외 시간엔 약 0.5%예요. 달러를 계속 갖고 거래하면 0으로 두세요.

해외주식 양도세: 미국 주식으로 1년 동안 번 돈에서 250만원을 뺀 나머지의 22%를 다음 해 5월에 내요. 국내 주식은 큰손(대주주)이 아니면 이 세금이 없어요.

저장하면 다음 매매부터 적용돼요. 이미 끝난 매매 기록은 바뀌지 않아요.

자세히 보기

승률: 판 횟수 중에서 돈을 번 횟수의 비율이에요. 10번 팔아서 6번 벌었으면 60%예요.

비용: 단타는 자주 사고팔아서 수수료·세금이 금방 쌓여요. 번 돈(실현손익)은 이 비용을 이미 뺀 금액이에요. 비용이 번 돈보다 크다면 너무 자주 사고팔고 있다는 신호일 수 있어요.

자세히 보기

지금 갖고 있는 주식은 "지금 바로 판다면 손에 남는 돈"(수수료·세금을 뺀 금액)으로 계산해요. 그래서 실제 계좌와 비슷해요.

종합: 국내 계좌(원)와 해외 계좌(달러)는 돈 단위가 달라서 그냥 더할 수 없어요. 그래서 각 계좌의 % 성적을 시작 금액 크기에 맞춰 섞어서 하나의 %로 만들었어요.

여기서는 실제/모의 매매가 일어나지 않아요
관심종목의 과거 데이터로만 전략을 실험하는 공간이에요. 여기서 좋다고 확인된 조합을 나중에 "자동매매" 탭의 리스크 규칙에 직접 반영하시면 돼요.

백테스트 (과거 데이터로 전략 비교)

관심종목의 과거 일봉으로 여러 전략(가중치·청산방식·사이징·시장필터 조합)을 오프라인으로 한 번에 비교해요. 국내 종목만 지원되고, 몇 초 정도 걸려요.

전략 상세 분석 (직접 설정해서 하나의 전략을 자세히 보기)

날짜·시장·종목을 직접 고르고, 전략의 가중치/매수문턱/청산/사이징까지 전부 바꿔가며 한 전략을 자세히 들여다볼 수 있어요. 국내·해외 중 하나의 시장만 골라서 보기 때문에(섞으면 거래일이 어긋나요), 해외 종목도 지원돼요.

진화형 탐색 (계속 더 나은 전략 찾기)

위 9개 고정 전략과 달리, 누를 때마다 지금까지 찾은 최고 조합을 조금씩 바꿔보며(돌연변이) 더 나은 조합을 탐색해요. 자동 실행은 매번 다른 과거 기간(1~4년 중 무작위)으로 백테스트해서 특정 구간에만 맞춰지지 않게 해요. 여기서 찾은 최신 조합은 자동매매의 "진화형(자동탐색)" 전략이 실시간으로 그대로 따라가고, 바뀔 때마다 "전략 변경 이력" 탭에 기록돼요(국내 종목만 해당). 기록은 계속 이어져요.

버튼을 안 눌러도 계속 탐색되게 하려면, cron-job.org에 /api/backtest?mode=evolve&auto=1&key=자동매매_시크릿키를 하루 1번 호출하는 작업을 하나 더 등록하세요(자동매매용 크론과 같은 키를 씁니다).

시장 상황 적응형 탐색 (구간별 전용 전략)

시장을 상승/하락/횡보(추세) × 평온/고변동(변동성) 최대 6구간으로 나누고, 구간마다 "그 구간에서만 매수"하도록 고정한 채로 따로 진화 탐색을 돌려요. 종목별 손절/익절은 구간과 무관하게 항상 그대로 실행되니 보유 중 포지션 추적이 끊기지 않아요. 자동매매의 "시장적응형" 전략이 오늘의 시장 상황을 매일 분류해서, 그 구간에 맞는 전략으로 자동 전환해요.

자세히 보기

칸에 적힌 돈은 그날 판 주식으로 확정된 손익이에요(수수료·세금을 뺀 금액). 산 것만 있고 안 판 날은 손익 없이 횟수만 보여요.

매매 기록은 날짜별 장부에 따로 쌓여서, 오래된 달도 그대로 볼 수 있어요. 다만 이 장부가 생기기 전에 이미 지워진 아주 오래된 기록은 되살릴 수 없어요.

API 키를 직접 입력할 필요가 없어요
LEDGER의 모든 시세·차트·재무·뉴스·실적 데이터는 서버(Vercel)에 등록된 API 키로 제공됩니다. 브라우저나 계정마다 키를 다시 입력할 필요가 없고, 공용 PC에서 접속해도 항상 바로 사용할 수 있어요.

시세 · 차트 · 재무지표 (한국투자증권 Open API)

국내(6자리 코드)와 해외(미국) 종목 모두 한국투자증권(KIS) Open API로 조회해요. 이 사이트를 운영하시는 분은 아래 설정이 필요해요.

  1. 한국투자증권 계좌 개설 후 apiportal.koreainvestment.com에서 Open API를 신청해 App Key/App Secret을 발급받으세요.
  2. Vercel 대시보드 → 이 프로젝트 → Settings → Environment Variables로 이동하세요.
  3. 이름 KIS_APP_KEY에 App Key를, 이름 KIS_APP_SECRET에 App Secret을 각각 등록하세요.
  4. Vercel에서 재배포(Redeploy)하면 자동으로 활성화돼요.

뉴스 · 실적 (Finnhub)

관련 뉴스와 실적(EPS) 데이터는 Finnhub에서 가져와요. 뉴스의 시장 영향도(호재/악재)는 Claude AI가 직접 분석해서 판단해요.

  1. finnhub.io에서 무료 계정을 만들고 API 키를 발급받으세요.
  2. Vercel 대시보드 → 이 프로젝트 → Settings → Environment Variables로 이동하세요.
  3. 이름 FINNHUB_API_KEY, 값은 발급받은 키를 입력하고 저장하세요.
  4. Vercel에서 재배포(Redeploy)하면 자동으로 활성화돼요.

AI 시그널 · AI 어닝콜

종목분석 화면에서 "이 종목이 왜 이렇게 움직였는지", 실적이 예상치를 넘었는지를 AI가 풀어서 설명해주는 기능이에요. 이 기능을 쓰려면 Vercel 프로젝트에 서버 설정을 한 번 추가해야 해요 (브라우저가 아니라 서버에서만 동작하는 키라 안전해요).

  1. console.anthropic.com에서 계정을 만들고 API 키를 발급받으세요.
  2. Vercel 대시보드 → 이 프로젝트 → Settings → Environment Variables로 이동하세요.
  3. 이름 ANTHROPIC_API_KEY, 값은 발급받은 키를 입력하고 저장하세요.
  4. Vercel에서 재배포(Redeploy)하면 자동으로 활성화돼요.

설정하지 않아도 나머지 기능은 그대로 잘 작동해요. AI 요약란에만 안내 문구가 표시돼요.
