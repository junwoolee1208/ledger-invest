Alpha Vantage API 키

실시간 시세와 재무데이터를 불러오려면 API 키가 필요합니다. alphavantage.co에서 무료로 발급받을 수 있습니다. 입력한 키는 이 브라우저에만 저장되며 서버로 전송되지 않습니다.

무료 티어 제한 안내
Alpha Vantage 무료 API는 1분당 5회 / 1일 25회 요청으로 제한됩니다. 앱은 중복 요청을 줄이기 위해 시세를 한동안 캐시해두지만, 관심종목이 많으면 한도에 빨리 도달할 수 있어요. 해외(특히 미국) 종목은 폭넓게 지원되지만, 국내 코스피/코스닥 종목은 일부만 지원되거나 지연 시세일 수 있습니다.
