API 키를 직접 입력할 필요가 없어요
LEDGER의 모든 시세·차트·재무·뉴스·실적 데이터는 서버(Vercel)에 등록된 API 키로 제공됩니다. 브라우저나 계정마다 키를 다시 입력할 필요가 없고, 공용 PC에서 접속해도 항상 바로 사용할 수 있어요.

시세 · 차트 · 재무지표 (한국투자증권 Open API)

국내(6자리 코드)와 해외(미국) 종목 모두 한국투자증권(KIS) Open API로 조회해요. 이 사이트를 운영하시는 분은 아래 설정이 필요해요.

  1. 한국투자증권 계좌 개설 후 apiportal.koreainvestment.com에서 Open API를 신청해 App Key/App Secret을 발급받으세요.
  2. Vercel 대시보드 → 이 프로젝트 → Settings → Environment Variables로 이동하세요.
  3. 이름 KIS_APP_KEY에 App Key를, 이름 KIS_APP_SECRET에 App Secret을 각각 등록하세요.
  4. Vercel에서 재배포(Redeploy)하면 자동으로 활성화돼요.

뉴스 · 실적 (Finnhub)

관련 뉴스와 실적(EPS) 데이터는 Finnhub에서 가져와요. 뉴스의 시장 영향도(호재/악재)는 Claude AI가 직접 분석해서 판단해요.

  1. finnhub.io에서 무료 계정을 만들고 API 키를 발급받으세요.
  2. Vercel 대시보드 → 이 프로젝트 → Settings → Environment Variables로 이동하세요.
  3. 이름 FINNHUB_API_KEY, 값은 발급받은 키를 입력하고 저장하세요.
  4. Vercel에서 재배포(Redeploy)하면 자동으로 활성화돼요.

AI 시그널 · AI 어닝콜

종목분석 화면에서 "이 종목이 왜 이렇게 움직였는지", 실적이 예상치를 넘었는지를 AI가 풀어서 설명해주는 기능이에요. 이 기능을 쓰려면 Vercel 프로젝트에 서버 설정을 한 번 추가해야 해요 (브라우저가 아니라 서버에서만 동작하는 키라 안전해요).

  1. console.anthropic.com에서 계정을 만들고 API 키를 발급받으세요.
  2. Vercel 대시보드 → 이 프로젝트 → Settings → Environment Variables로 이동하세요.
  3. 이름 ANTHROPIC_API_KEY, 값은 발급받은 키를 입력하고 저장하세요.
  4. Vercel에서 재배포(Redeploy)하면 자동으로 활성화돼요.

설정하지 않아도 나머지 기능은 그대로 잘 작동해요. AI 요약란에만 안내 문구가 표시돼요.
